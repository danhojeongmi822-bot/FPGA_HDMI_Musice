后续任务依次新增 任务02_任务名称.md 等文件，并更新本索引。同一任务的补充修正追加在原文件，保留原结论的证据和变更原因，不随意覆盖历史。

每份记录至少包含：任务目标、修改前情况、具体改动和相关文件、实际效果、验证结果与证据、问题和限制、后续工作、补充记录。实际未测的效果不能写成已实现或已通过。
